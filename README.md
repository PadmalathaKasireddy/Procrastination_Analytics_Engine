# Procrastination Analytics Engine

## Overview

The **Procrastination Analytics Engine** is a Data Analytics project designed to analyze procrastination behavior patterns and productivity trends using data-driven techniques. The project helps identify how procrastination affects work habits, task completion, focus levels, and overall productivity.

This project demonstrates practical skills in:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Statistical Analysis
- Productivity Pattern Analysis

---

# Objective

The main objective of this project is to:

- Analyze procrastination-related behavior
- Identify productivity trends
- Understand task completion patterns
- Generate meaningful insights using analytics
- Visualize behavioral data effectively

---

# Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Visualization of productivity trends
- Behavioral pattern analysis
- Correlation analysis
- Insight generation using graphs and charts
- User-friendly analytics workflow

# How to Run the Project

## Step 1 — Clone Repository

```bash
git clone https://github.com/PadmalathaKasireddy/Procrastination_Analytics_Engine.git
```

## Step 2 — Open Project Folder

```bash
cd Procrastination_Analytics_Engine
```

## Step 3 — Install Dependencies

```bash
pip install -r requirements.txt
```

## Step 4 — Run Jupyter Notebook

```bash
jupyter notebook
```

Open the notebook and execute the cells.
